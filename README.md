# Stack Fund Launch

A decentralized crowdfunding platform built on the Stacks blockchain using Clarity smart contracts.

## Overview

Stack Fund Launch enables users to create and manage crowdfunding projects on the Stacks blockchain. The platform allows project creators to set funding goals and deadlines, while backers can pledge STX tokens to support projects they believe in.

## Features

- Create crowdfunding projects with customizable goals and deadlines
- Pledge STX tokens to support projects
- Vote-based release mechanism for project funds
- Secure fund management through smart contracts
- Automatic refund system if project goals aren't met
